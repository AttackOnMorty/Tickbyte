# Change colour follows the tape

An advance is accent red; a decline is success green; flat stays `--text-disabled`. This is East-Asian tape, not Western “green = good.” Skill status roles (up = success, down = accent) were considered and rejected — a rising print is data, not a health state. `[LOST]` remains accent: that is the interrupt. On the light white card, green uses the darker paper fork so 16px type still contrasts.
